Phone2Act: A Low-Cost, Hardware-Agnostic Teleoperation System for Scalable VLA Data Collection

(Manuscript in preparation)

Engineered a scalable, low-cost teleoperation framework addressing the data scarcity bottleneck in Vision-Language-Action (VLA) models. The system utilizes a custom Android application with ARCore to transform a commodity smartphone into a high-frequency (50Hz), 6-DoF spatial controller. Built on a modular ROS 2 architecture, it achieves an average end-to-end latency of ~395ms while integrating crucial safety features like a "Zero-Jump" filter (default 60mm) to prevent erratic robotic movements.

  • VLA-Ready Data Pipeline: Developed a Universal Recorder that synchronizes external RGB camera streams with 20Hz robot state feedback. The pipeline natively formats data into LeRobot standard (Parquet and MP4) and includes a shortest-path wrapping algorithm to ensure continuous Euler angles, eliminating massive numerical jumps during model training.
  • Model Fine-Tuning & Deployment: Collected a dataset of 150 episodes and successfully fine-tuned the NVIDIA GR00T N1.5 VLA model. Evaluated on a Dobot CR5, the model demonstrated robust real-world execution of a multi-stage task (picking up a thermocol ball and placing it in a purple basket), validating the high-fidelity of the smartphone-based trajectories.
  • Hardware Agnosticism & Bimanual Scaling: Designed interchangeable standard-to-specific bridge nodes to decouple control logic from specific robot hardware. Demonstrated system scalability by successfully deploying bimanual teleoperation on open-source, 3D-printed LeRobot SO-101 arms using two smartphones.
